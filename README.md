## Building from the source

If you want to build apim-policies from the source code:

1. Install Java 11 (https://adoptopenjdk.net/archive.html)
1. Install Apache Maven 3.x.x (https://maven.apache.org/download.cgi#)
1. Get a clone or download the source from this repository (https://github.com/wso2-extensions/apim-policies.git).
1. Check out branch master as follows:\
``git checkout master``
1. Navigate to the ``apim-policies`` directory and run the following Maven command.\
 ``mvn clean install``
